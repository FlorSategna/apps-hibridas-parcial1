MOVIES API

Bienvenido a Movies API

Acá podés explorar información sobre películas, géneros, reseñas y usuarios. La API permite crear, buscar, actualizar y eliminar registros, además de filtrar películas por año o género y consultar reseñas asociadas.

Endpoints principales

  • Películas — CRUD, búsqueda y filtros
  • Géneros — listado y gestión de géneros
  • Reseñas — comentarios y puntajes de usuarios
  • Usuarios — listado de usuarios
